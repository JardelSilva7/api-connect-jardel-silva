# API Connect

## Objetivo

A API Connect é uma API REST desenvolvida como MVP para gerenciamento de usuários. A aplicação permite cadastrar, consultar, atualizar e remover usuários por meio de requisições HTTP, utilizando respostas em formato JSON.

## Tecnologias utilizadas

- Node.js
- Express
- JavaScript
- JSON
- Git e GitHub

A persistência dos dados é realizada provisoriamente por meio de um array em memória, sem utilização de banco de dados.
